# হস্তাক্ষর জেনারেটর (Text2Handwriting)

> সাধারণ টেক্সটকে বাস্তবসম্মত হস্তলিখিত পৃষ্ঠায় রূপান্তর করুন, কোনো সার্ভার আপলোড ছাড়াই সম্পূর্ণ ব্রাউজারে।

হাতে লেখা হোমওয়ার্ক, রিডিং নোট, মিটিংয়ের কার্যবিবরণী এবং আনুষ্ঠানিক চিঠির জন্য বিশেষভাবে নকশাকৃত। সাধারণ হস্তাক্ষর টুলের মতো কেবল ফন্ট পরিবর্তন করার পরিবর্তে, Text2Handwriting সিড-নিয়ন্ত্রিত ছদ্ম-এলোমেলো বিচ্যুতির মাধ্যমে অক্ষরের আকার, ঘূর্ণন, বেসলাইনের কম্পন এবং কালির ঘনত্বে বাস্তবসম্মত পরিবর্তন আনে। এটি কোনো অ্যাকাউন্ট ছাড়াই সম্পূর্ণ আপনার ব্রাউজারে স্থানীয়ভাবে কাজ করে।

## সামঞ্জস্যতা ম্যাট্রিক্স

| মাত্রা | বিবরণ |
|---|---|
| পরিবেশ | আধুনিক ডেস্কটপ ও মোবাইল ব্রাউজার, ১০০% ক্লায়েন্ট-সাইড; সংকীর্ণ স্ক্রিনে স্বয়ংক্রিয়ভাবে এক-কলাম সম্পাদনা/প্রিভিউ কর্মক্ষেত্রে রূপ নেয়, উপরের সেগমেন্ট বাটন দিয়ে পাল্টানো যায় (Chrome ও Edge 103+ লোকাল ফন্ট তালিকাভুক্ত করতে পারে, Safari ও Firefox অন্তর্নির্মিত সনাক্তকরণ ব্যবহার করে) |
| ইনপুট ফরম্যাট | সরাসরি টেক্সট পেস্ট করুন, `.txt` / `.md` ফাইল আপলোড করুন (GB18030 ফলব্যাক সহ কঠোর UTF-8 যাচাইকরণ) বা `.docx` (ক্লায়েন্ট-সাইড এক্সট্র্যাকশন) |
| কাগজের স্টাইল | ৬টি অন্তর্নির্মিত কাগজের ধরন (রুল টানা খাতা, গ্রিড, সাদা A4, ইংরেজি চার লাইন, ক্রাফ্ট পেপার, ডট গ্রিড) এবং স্বয়ংক্রিয় ফিটিং সহ কাস্টম কাগজের ছবি আপলোড |
| কলম ও টেক্সচার | ৪টি বাস্তবসম্মত কলমের ধরন (জেল পেন, ফাউন্টেন পেন, পেন্সিল, বলপয়েন্ট); ডিফিউজ আলো, ভাঁজের ছায়া, কোণার ভিননেট ও ভিন্টেজ এজিং প্রভাব |
| এক্সপোর্ট বিকল্প | বর্তমান পেজ PNG / JPG, সকল পেজ ZIP আর্কাইভ, মাল্টি-পেজ PDF, এবং লুকানো iframe-এর মাধ্যমে রিয়েল-মিলিমিটার মুদ্রণ (সর্বোচ্চ ~435 DPI) |
| টাইপোগ্রাফি | ১৮টি ভাষায় সম্পূর্ণ ইন্টারফেস; স্মার্ট লাইন ব্রেক, CJK বিরামচিহ্ন নিয়ম, স্বাভাবিক লিগেচার সহ আরবি দ্বিমুখী লেআউট (BiDi RTL) |
| অফলাইন ও সিঙ্ক | ডেস্কটপ ও মোবাইলে ইনস্টলযোগ্য PWA; ট্যাবের মধ্যে Web Locks সুরক্ষা, ২৫০ms স্বয়ংক্রিয় ড্রাফট সেভ এবং সংরক্ষণ না করা সতর্কবার্তা |

## মূল বৈশিষ্ট্যসমূহ

- **বাস্তবসম্মত হস্তাক্ষর**: সিড-নিয়ন্ত্রিত ছদ্ম-এলোমেলো বিচ্যুতি অক্ষরের আকার, ফাঁক, ঢাল, বেসলাইন বিচ্যুতি, স্ট্রোকের ঘনত্ব এবং লেখার ক্লান্তি নিয়ন্ত্রণ করে। প্রতিটি রেন্ডার অনন্য এবং সিড সংরক্ষণের মাধ্যমে একই ফলাফল ১০০% পুনরায় তৈরি করা সম্ভব।
- **স্মার্ট টাইপোগ্রাফি ও দ্বিমুখী টেক্সট**: ১৮টি ভাষার জন্য সম্পূর্ণ স্থানীয়করণ; লাইন শুরু/শেষের নিয়ম, অনুচ্ছেদের ইনডেন্ট, স্বয়ংক্রিয় পৃষ্ঠাকরণ এবং ডানদিকে স্বাক্ষর সারিবদ্ধকরণ; আরবি লিপির স্বাভাবিক সংযোগ এবং বন্ধনী সুরক্ষা।
- **কাগজ ও ছবির টেক্সচার**: লাইন স্পেসিং এবং মার্জিনের সূক্ষ্ম সমন্বয়; বর্গাকার গ্রিড সেল; A4 মাপে আপলোড করা ছবির স্বয়ংক্রিয় সমন্বয়; স্বাভাবিক ভাঁজ ও আলোর ছায়া।
- **যেকোনো ফন্ট**: ৮টি ওপেন সোর্স হস্তাক্ষর ফন্ট (৪টি অফলাইনে অন্তর্ভুক্ত + ৪টি Google Fonts থেকে লোড)। সিস্টেম ফন্ট, Google Fonts লোড করুন বা `.ttf` / `.otf` / `.woff` / `.woff2` ফাইল ড্রপ করুন (নিজের হাতের লেখার ফন্ট ব্যবহারের জন্য Calligraphr সমর্থিত)।
- **স্বাভাবিক কাটাকুটি ও সংশোধন**: সমন্বয়যোগ্য সম্ভাবনা সহ ১৩টি স্ট্রাইক-থ্রু শৈলী (একক রেখা, দ্বৈত রেখা, তরঙ্গায়িত, স্ক্রিবল); ভুল শব্দ কেটে উপরে সংশোধন লিখুন; ক্যানভাস টুলবারে ব্রাশ দিয়ে তীর, স্কেচ ও গোল দাগ আঁকা যায়, সাথে ইরেজার, এই পৃষ্ঠার হাতের আঁকা মুছে ফেলা এবং মার্জিন নির্দেশিকা।
- **লেখার শৈলী প্রিসেট**: ৪টি প্রিসেট (মেধাবী মনোযোগী ছাত্র, স্বাভাবিক দৈনন্দিন নোট, তাড়াহুড়োয় লেখা, বিদ্যালয়ের সাধারণ বাড়ির কাজ) এক ক্লিকে বিচ্যুতির তীব্রতা, লেখার টেক্সচার ও সংশোধনের সম্ভাবনা প্রয়োগ করে।

## মার্কআপ সিনট্যাক্স

সঠিক কাটাকুটি এবং হাইলাইট নির্দিষ্ট করতে টেক্সটে সরাসরি ইনলাইন মার্কআপ ট্যাগ ব্যবহার করুন:

| সিনট্যাক্স | ভিজ্যুয়াল প্রভাব |
|---|---|
| `~~ভুল~~` বা `[del]ভুল[/del]` | টেক্সট কেটে দিন |
| `[del:সংশোধন]ভুল[/del]` | ভুল শব্দ কেটে উপরে সংশোধন লিখুন |
| `[u]হাইলাইট[/u]` | তরঙ্গায়িত আন্ডারলাইন |
| `[circle]হাইলাইট[/circle]` | টেক্সট বৃত্তাকার করুন (উপনাম `[圈]…[/圈]`) |
| `[box]হাইলাইট[/box]` | টেক্সট বাক্সে আবদ্ধ করুন (উপনাম `[框]…[/框]`) |
| `[right]স্বাক্ষর[/right]` | সম্পূর্ণ লাইনটি ডানে সারিবদ্ধ করুন (উপনাম `[靠右]…[/靠右]`) — স্বাক্ষর ও তারিখের জন্য |

## দ্রুত শুরু

1. [অনলাইন ডেমো](https://shouxie.newzone.top) খুলুন বা টেক্সট ফাইল (`.txt` / `.docx` / `.md`) আমদানি করুন।
২. বাম প্যানেল থেকে কাগজের শৈলী, ফন্ট এবং লেখার প্রিসেট বেছে নিন, প্রয়োজনে বিচ্যুতির মাত্রা বা ছবির আলো সমন্বয় করুন (মোবাইলে উপরের "সম্পাদনা / পূর্বরূপ" সেগমেন্ট বাটন দিয়ে দুটি কলামের মধ্যে পাল্টান)।
৩. উচ্চ রেজোলিউশনের ছবি (PNG / JPG), সব পেজের ZIP, মাল্টি-পেজ PDF ডাউনলোড করতে বা সত্যিকারের মিলিমিটার আকারে প্রিন্ট করতে উপরে "এক্সপোর্ট" এ ক্লিক করুন।

## সীমাবদ্ধতা

- ল্যাটিন এবং CJK টাইপোগ্রাফি দ্রুত প্রক্রিয়াকরণ নিশ্চিত করতে আনুমানিক গ্লিফ প্রস্থ ব্যবহার করে (আরবি টেক্সট নেটিভ Canvas পরিমাপ ব্যবহার করে); অপ্রচলিত হস্তাক্ষর ফন্টের ক্ষেত্রে লাইনের শেষ অংশে সামান্য তারতম্য হতে পারে।
- ব্রাউজার প্রিন্টিং কেবল বর্তমান পৃষ্ঠা প্রিন্ট করে; সম্পূর্ণ মাল্টি-পেজ ডকুমেন্ট প্রিন্ট করতে PDF এক্সপোর্ট ব্যবহার করুন।
- Safari 16-এর নিচের সংস্করণে `ctx.filter` সমর্থনের অভাবে ব্যাকগ্রাউন্ড উজ্জ্বলতা এবং বৈসাদৃশ্য সমন্বয় কাজ করে না।
- ফ্রিহ্যান্ড ড্রয়িং লেয়ার মেমরিতে পৃষ্ঠা সূচকের সাথে আবদ্ধ থাকে; বড় টেক্সট পরিবর্তনের ফলে পৃষ্ঠাকরণ পরিবর্তন হলে ড্রয়িং স্থানান্তরিত হতে পারে।
- অন্তর্নির্মিত ফন্টগুলির মধ্যে ৪টি অফলাইনে প্যাকেজের সাথে আসে; বাকি ৪টি (Liu Jian Mao Cao, ZCOOL XiaoWei, Caveat, Kalam) রানটাইমে Google Fonts থেকে লোড হয় এবং ইন্টারনেট না থাকলে বা ইন্ট্রানেটে সিস্টেম ফন্টে ফিরে যায়।
- স্থানীয়ভাবে আমদানি করা `.ttf` / `.otf` / `.woff` / `.woff2` ফন্ট ফাইল কেবল বর্তমান ব্রাউজার সেশনের মেমরিতে থাকে এবং পেজ রিফ্রেশের পরে পুনরায় নির্বাচন করতে হয়।

## স্থানীয় ডেভেলপমেন্ট

প্রয়োজন: Node.js **22.12+ / 24+ / 26+**:

```bash
npm install
npm run dev        # http://localhost:5173/ এ স্থানীয় ডেভেলপমেন্ট সার্ভার শুরু করুন
npm test           # Vitest ইউনিট টেস্ট চালান
npm run lint       # স্ট্যাটিক কোড বিশ্লেষণ (oxlint)
npm run build      # প্রোডাকশন বিল্ড (tsc + vite)
```

`dist/` ফোল্ডারে প্রস্তুত ফাইলগুলি আপেক্ষিক পাথ (`base: './'`) ব্যবহার করে এবং GitHub Pages বা যেকোনো ওয়েব সার্ভারে হোস্ট করা যায়। আরও বিস্তারিত জানার জন্য [docs/development.md](../development.md) দেখুন।
