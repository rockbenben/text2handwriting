# हस्तलेखन जनरेटर (Text2Handwriting)

> सादे पाठ को यथार्थवादी हस्तलिखित पृष्ठों में बदलें, बिना किसी सर्वर अपलोड के पूरी तरह से अपने ब्राउज़र में।

हस्तलिखित गृहकार्य, पढ़ने के नोट्स, बैठक विवरण और औपचारिक पत्रों के लिए डिज़ाइन किया गया। सामान्य हस्तलेखन उपकरणों के विपरीत जो केवल यांत्रिक रूप से फ़ॉन्ट बदलते हैं, Text2Handwriting अक्षर के आकार, रोटेशन, बेसलाइन उतार-चढ़ाव और स्याही के घनत्व में बीज-नियंत्रित छद्म-यादृच्छिक विक्षोभ लागू करता है। यह बिना किसी खाते या सर्वर अपलोड के पूरी तरह से आपके ब्राउज़र में काम करता है।

## संगतता मैट्रिक्स

| आयाम | विवरण |
|---|---|
| वातावरण | आधुनिक डेस्कटॉप और मोबाइल ब्राउज़र, 100% क्लाइंट-साइड निष्पादन (Chrome / Edge 103+ स्थानीय फ़ॉन्ट स्कैन कर सकते हैं, Safari / Firefox अंतर्निहित पहचान का उपयोग करते हैं) |
| इनपुट प्रारूप | टेक्स्ट सीधे पेस्ट करें, `.txt` / `.md` फ़ाइलें अपलोड करें (GB18030 फ़ॉलबैक के साथ सख्त UTF-8 सत्यापन), या `.docx` (क्लाइंट-साइड निष्कर्षण) |
| कागज़ शैलियाँ | 6 अंतर्निहित कागज़ प्रकार (लाइन वाली नोटबुक, ग्रिड, सादा A4, अंग्रेज़ी चार-पंक्ति, क्राफ्ट पेपर, डॉट ग्रिड) और स्वचालित समायोजन के साथ कस्टम कागज़ फोटो अपलोड |
| पेन और बनावट | 4 यथार्थवादी पेन प्रकार (जेल पेन, फाउंटेन पेन, पेंसिल, बॉलपॉइंट); विसरित प्रकाश, मोड़ने की सिलवटों की छाया, विगनेट और विंटेज पेपर प्रभाव |
| निर्यात विकल्प | वर्तमान पृष्ठ PNG / JPG, सभी पृष्ठ ZIP संग्रह, बहु-पृष्ठ PDF, और छिपे हुए iframe के माध्यम से मिलीमीटर-सटीक मुद्रण (लगभग ~435 DPI तक) |
| टाइपोग्राफी | 18 भाषाओं में पूर्ण इंटरफ़ेस; स्मार्ट लाइन ब्रेक, CJK विराम चिह्न नियम, प्राकृतिक कर्सिव जुड़ाव के साथ अरबी द्विदिशात्मक लेआउट (BiDi RTL) |
| ऑफ़लाइन और सिंक | डेस्कटॉप और मोबाइल पर इंस्टॉल करने योग्य PWA; टैब के बीच Web Locks समवर्ती सुरक्षा, 250ms ड्राफ्ट ऑटो-सेव और बिना सहेजे परिवर्तन चेतावनी |

## मुख्य विशेषताएं

- **यथार्थवादी हस्तलेखन**: बीज-नियंत्रित छद्म-यादृच्छिक विक्षोभ अक्षर के आकार, रिक्ति, झुकाव, बेसलाइन बहाव, स्ट्रोक की मोटाई और लिखने की थकान को नियंत्रित करता है। प्रत्येक रेंडर अद्वितीय है और बीज को सहेजकर समान आउटपुट को फिर से बनाया जा सकता है।
- **स्मार्ट टाइपोग्राफी और द्विदिशात्मक पाठ**: 18 भाषाओं के लिए पूर्ण स्थानीयकरण; पंक्ति प्रारंभ/अंत नियम, पैराग्राफ इंडेंट, स्वचालित पृष्ठांकन और दाएँ संरेखित हस्ताक्षर; लैटिन लिपियों के लिए शब्द-विभाजन सुरक्षा; कोष्ठक सुरक्षा के साथ अरबी कर्सिव जुड़ाव।
- **कागज़ और फ़ोटो बनावट**: पंक्ति रिक्ति और हाशिए का पूर्ण नियंत्रण; वर्गाकार ग्रिड सेल; A4 आकार में फ़ोटो का स्वचालित संरेखण; प्राकृतिक सिलवटें और छाया प्रभाव।
- **कोई भी फ़ॉन्ट**: 4 ओपन-सोर्स हस्तलेखन फ़ॉन्ट अंतर्निहित (100% ऑफ़लाइन)। सिस्टम फ़ॉन्ट, Google Fonts लोड करें या `.ttf` / `.otf` फ़ाइलें छोड़ें (अपनी लिखावट का उपयोग करने के लिए Calligraphr के साथ संगत)।
- **प्राकृतिक सुधार और काट-छांट**: समायोज्य संभावना के साथ 13 स्ट्राइक-थ्रू शैलियाँ (एकल रेखा, दोहरी, लहरदार, स्क्रिबल); गलत अक्षरों को काटकर ऊपर सुधार लिखें; तीर और नोट्स के लिए अंतर्निहित ड्राइंग लेयर।
- **लेखन व्यक्तित्व**: पेन और रिक्ति को तुरंत कॉन्फ़िगर करने के लिए 4 तैयार प्रीसेट (उत्कृष्ट छात्र, त्वरित नोट्स, जल्दबाजी का ड्राफ्ट, औपचारिक प्रतिलिपि)।

## मार्कअप सिंटैक्स

सटीक स्ट्राइक-थ्रू और हाइलाइटिंग निर्दिष्ट करने के लिए टेक्स्ट में सीधे इनलाइन मार्कअप टैग का उपयोग करें:

| सिंटैक्स | रेंडर प्रभाव |
|---|---|
| `~~गलती~~` या `[del]गलती[/del]` | टेक्स्ट को स्ट्राइक-थ्रू करें |
| `[del:सुधार]गलती[/del]` | गलती को काटें और लाइन के ऊपर सुधार लिखें |
| `[u]हाइलाइट[/u]` | लहरदार रेखांकन |
| `[circle]हाइलाइट[/circle]` | टेक्स्ट के चारों ओर घेरा बनाएं (उपनाम `[圈]…[/圈]`) |
| `[box]हाइलाइट[/box]` | टेक्स्ट के चारों ओर बॉक्स बनाएं (उपनाम `[框]…[/框]`) |

## त्वरित शुरुआत

1. [ऑनलाइन डेमो](https://shouxie.newzone.top) खोलें या टेक्स्ट फ़ाइल (`.txt` / `.docx` / `.md`) आयात करें।
2. बाएँ पैनल से कागज़ शैली, हस्तलेखन फ़ॉन्ट और लेखन व्यक्तित्व चुनें।
3. उच्च-रिज़ॉल्यूशन छवियां, PDF डाउनलोड करने या सीधे प्रिंटर पर भेजने के लिए शीर्ष पर "निर्यात" पर क्लिक करें।

## ज्ञात सीमाएं

- लैटिन और CJK टाइपोग्राफी बड़े दस्तावेज़ों पर त्वरित प्रसंस्करण सुनिश्चित करने के लिए अनुमानित वर्ण चौड़ाई का उपयोग करती है (अरबी मूल Canvas माप का उपयोग करती है); अत्यधिक असामान्य फ़ॉन्ट में लाइन के छोर थोड़े भिन्न हो सकते हैं।
- ब्राउज़र प्रिंटिंग केवल वर्तमान पृष्ठ प्रिंट करती है; संपूर्ण बहु-पृष्ठ दस्तावेज़ प्रिंट करने के लिए PDF निर्यात का उपयोग करें।
- Safari 16 से नीचे के संस्करणों में `ctx.filter` समर्थन की कमी के कारण पृष्ठभूमि की चमक और कंट्रास्ट समायोजन काम नहीं करते हैं।
- फ्रीहैंड ड्राइंग परत मेमोरी में पृष्ठ सूचकांक से बंधी होती है; बड़े टेक्स्ट संपादन जो पृष्ठांकन बदलते हैं, वे स्ट्रोक को स्थानांतरित कर सकते हैं।
- स्थानीय रूप से आयातित फ़ॉन्ट फ़ाइलें केवल वर्तमान ब्राउज़र सत्र मेमोरी में रहती हैं और पेज रीफ़्रेश के बाद फिर से चुनी जानी चाहिए।

## स्थानीय विकास

आवश्यकताएँ: Node.js **22.12+ / 24+ / 26+**:

```bash
npm install
npm run dev        # स्थानीय विकास सर्वर http://localhost:5173/ पर शुरू करें
npm test           # Vitest यूनिट टेस्ट चलाएं
npm run lint       # स्थिर कोड विश्लेषण (oxlint)
npm run build      # उत्पादन बिल्ड (tsc + vite)
```

`dist/` फ़ोल्डर में उत्पन्न फ़ाइलें सापेक्ष पथों (`base: './'`) का उपयोग करती हैं और इन्हें GitHub Pages या किसी भी वेब सर्वर पर होस्ट किया जा सकता है। अधिक विवरण के लिए [docs/development.md](../development.md) देखें।
