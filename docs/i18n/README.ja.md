# 手書き原稿ジェネレーター (Text2Handwriting)

> テキストをリアルな手書き原稿にレイアウト。課題・反省文・読書ノートを完全ローカルで生成。

手書きの提出物、読書ノート、反省文、手紙の作成に最適です。フォントを機械的に置き換える従来のツールとは異なり、乱数シードを用いて文字サイズ・傾き・ベースラインを文字ごとに揺らぎを持たせ、インクの濃淡やリアルな訂正痕を再現します。サーバーへのアップロードやアカウント登録は不要で、ブラウザ内で完結します。

## 対応仕様

| 項目 | 説明 |
|---|---|
| 動作環境 | モダンなデスクトップ／モバイルブラウザで、純粋なクライアントサイド実行。狭い画面では編集／プレビューの1カラムワークスペースに自動で切り替わり、上部のセグメントボタンで両者を切り替えられます（Chrome / Edge 103+ で端末内のインストール済みフォントを列挙可能、Safari / Firefox では自動フォールバック） |
| 入力形式 | テキスト貼り付け、`.txt` / `.md`（厳密な UTF-8 検証および GB18030 フォールバック）、`.docx`（クライアント側での抽出） |
| 用紙スタイル | 6 種類の用紙（横罫線ノート、原稿用紙、A4 白紙、英語 4 本線、クラフト便箋、ドット方眼）、スマホで撮影した白紙画像の自動縮尺対応 |
| ペンと質感 | ゲルインクペン、万年筆、鉛筆、ボールペンの 4 種類；環境拡散光、折り目、周辺減光（ビネット）、経年変色効果 |
| 出力形式 | 現在のページ PNG / JPG、全ページ ZIP 一括保存、複数ページ PDF、非表示 iframe によるミリ単位実寸印刷（最高約 435 DPI） |
| 言語と組版 | 18 言語の完全ローカライズ；禁則処理、英単語の途中改行防止、アラビア語などの RTL 双方向組版と連結変形（Cursive Joining） |
| オフライン | PWA 対応（デスクトップ・スマホへのインストール可能）；Web Locks による複数タブ間の排他保存と未保存離脱警告 |

## 主な機能

- **リアルな手書き感**：シード値による擬似乱数揺らぎ——文字サイズ、字間、傾き、行全体のドリフト、インクの滲み、筆記疲労効果。シード値を記録すれば同じ出力を完全に再現できます。
- **高度な組版と双方向テキスト**：禁則処理、段落インデント、複数ページの自動改ページ、署名の右寄せ対応。アラビア語などの双方向テキスト（BiDi RTL）やネイティブ連結変形、括弧類の保護を標準サポート。
- **用紙と実写質感**：行間や余白を自由に調整可能。原稿用紙の正方形セル自動連動、撮影写真の A4 比率自動収容、光の陰影や中央の折り目、角のビネットでリアルな紙質を再現。
- **自由なフォント読み込み**：8 種類のオープンソース手書きフォント（4 種類はパッケージ同梱でオフライン利用可 + 4 種類は Google Fonts からオンライン読み込み）。端末フォントや Google Fonts の読み込み、`.ttf` / `.otf` / `.woff` / `.woff2` のドラッグ＆ドロップ対応（Calligraphr で自作したフォントも利用可能）。
- **リアルな訂正・注釈**：13 種類の取り消し線スタイル（1 本線、2 本線、波線、塗りつぶしなど）を自然な確率で適用。文字の上に訂正文字を書き足したり、強調の丸囲みや枠囲みが可能。キャンバスツールバーではブラシで矢印・スケッチ・丸囲みを手描きでき、消しゴム、このページの手描き消去、マージン参考線にも対応。
- **筆記スタイルプリセット**：几帳面な優等生、気ままなメモ帳、急ぎの走り書き、標準的な提出課題の 4 種類をワンクリックで切り替え、揺らぎの強さ・書き味・訂正の確率をまとめて適用します。

## マークアップ記法

テキスト内にタグを記述することで、特定の位置に取り消し線や強調を明示的に指定できます：

| 記法 | 表示効果 |
|---|---|
| `~~誤字~~` または `[del]誤字[/del]` | 取り消し線 |
| `[del:訂正]誤字[/del]` | 取り消し線を引き、行の上に訂正文字を記入 |
| `[u]重要[/u]` | 波線の下線 |
| `[circle]重要[/circle]` | 丸囲み（別名 `[圈]…[/圈]`） |
| `[box]重要[/box]` | 四角枠（別名 `[框]…[/框]`） |
| `[right]署名[/right]` | 行全体を右寄せ（別名 `[靠右]…[/靠右]`）、署名や日付に最適 |

## クイックスタート

1. [オンラインデモ](https://shouxie.newzone.top) を開くか、テキストファイル（`.txt` / `.docx` / `.md`）を読み込みます。
2. 左パネルで用紙スタイル、フォント、筆記スタイルを選び、必要に応じて揺らぎや実写のライティングを調整します（スマホでは上部の「編集 / プレビュー」セグメントボタンで左右の列を切り替えます）。
3. ヘッダーの「エクスポート」をクリックし、高解像度画像（PNG / JPG）、全ページ ZIP、複数ページ PDF のダウンロード、またはミリ単位の実寸印刷を実行します。

## 制限事項

- 日本語・中国語・英語の組版は高速処理のため文字幅の推定値を使用します（アラビア語のみ Canvas 原生測定を使用）。標準的なプロポーションと大きく異なる特殊フォントでは行末位置がわずかにずれる場合があります。
- ブラウザ印刷は現在のページのみ対象です。全ページを印刷する場合は PDF 出力を利用してください。
- Safari 16 未満では `ctx.filter` がサポートされていないため、背景画像の明るさ・コントラスト調整が無効になります。
- 手書き描画レイヤーはページ番号に紐づいてメモリ内に保持されます。テキストの大幅な編集で改ページが変わると描画位置がずれる場合があります。
- 内蔵フォントのうち 4 種類はパッケージ同梱でオフライン利用可能です。残り 4 種類（Liu Jian Mao Cao、ZCOOL XiaoWei、Caveat、Kalam）は実行時に Google Fonts から読み込まれ、オフラインや社内ネットワークではシステムフォントにフォールバックします。
- ローカルからインポートした `.ttf` / `.otf` / `.woff` / `.woff2` フォントファイルは現在のセッションのメモリにのみ保持され、ページ再読み込み後は再インポートが必要です。

## ローカル開発

Node.js **22.12+ / 24+ / 26+** が必要です：

```bash
npm install
npm run dev        # 開発サーバー起動 http://localhost:5173/
npm test           # テスト実行 (Vitest)
npm run lint       # 静的解析 (oxlint)
npm run build      # 本番ビルド (tsc + vite)
```

ビルド生成物 `dist/` は相対パスを使用しているため、GitHub Pages やイントラネット環境にそのままデプロイできます。詳細なアーキテクチャや言語追加ガイドは [開発ドキュメント (docs/development.md)](../development.md) を参照してください。
