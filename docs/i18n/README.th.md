# โปรแกรมสร้างลายมือ (Text2Handwriting)

> แปลงข้อความธรรมดาเป็นหน้ากระดาษลายมือเสมือนจริง ทำงานในเบราว์เซอร์ของคุณโดยตรงโดยไม่ต้องอัปโหลดขึ้นเซิร์ฟเวอร์

ออกแบบมาสำหรับการบ้านลายมือ บันทึกการอ่าน รายงานการประชุม และจดหมายทางการ แตกต่างจากเครื่องมือทั่วไปที่เพียงแค่เปลี่ยนฟอนต์อย่างแข็งทื่อ Text2Handwriting ใช้การสุ่มรบกวนจำลองที่ควบคุมด้วย seed กับขนาดตัวอักษร การหมุน การสั่นไหวของเส้นฐาน และความหนาแน่นของหมึก ทำงานในเบราว์เซอร์ของคุณ 100% โดยไม่ต้องลงทะเบียนหรืออัปโหลดข้อมูลไปยังเซิร์ฟเวอร์ภายนอก

## ตารางความเข้ากันได้

| มิติ | รายละเอียด |
|---|---|
| สภาพแวดล้อม | เบราว์เซอร์สมัยใหม่บนเดสก์ท็อปและมือถือ ทำงานบนฝั่งไคลเอนต์ 100%; บนหน้าจอแคบจะสลับเป็นพื้นที่ทำงานคอลัมน์เดียวสำหรับแก้ไข/ดูตัวอย่างอัตโนมัติ พร้อมปุ่มแบ่งส่วนด้านบนสำหรับสลับ (Chrome และ Edge 103+ สามารถค้นหาฟอนต์ในเครื่องได้, Safari และ Firefox ใช้ระบบตรวจจับในตัว) |
| รูปแบบการนำเข้า | วางข้อความโดยตรง, อัปโหลดไฟล์ `.txt` / `.md` (ตรวจสอบ UTF-8 อย่างเข้มงวดพร้อมรองรับ GB18030) หรือไฟล์ `.docx` (สกัดข้อความในเครื่อง) |
| รูปแบบกระดาษ | กระดาษในตัว 6 แบบ (มีเส้นบรรทัด, ตารางกริด, A4 เปล่า, บรรทัด 4 เส้นสำหรับภาษาอังกฤษ, กระดาษคราฟต์, กริดจุด) พร้อมอัปโหลดภาพถ่ายกระดาษของตนเองและปรับขนาดอัตโนมัติ |
| ปากกาและพื้นผิว | ฟิสิกส์ปากกาจริง 4 รูปแบบ (ปากกาเจล, ปากกาหมึกซึม, ดินสอ, ปากกาลูกลื่น); แสงรอบข้างแบบกระจาย, เงารอยพับ, ขอบมืด และเอฟเฟกต์กระดาษเก่า |
| ตัวเลือกการส่งออก | หน้าปัจจุบันเป็น PNG / JPG, ทุกหน้าเป็นไฟล์บีบอัด ZIP, PDF หลายหน้า และการพิมพ์ขนาดมิลลิเมตรจริงแบบไม่สูญเสียความละเอียดผ่าน iframe ซ่อน (สูงสุด ~435 DPI) |
| การจัดพิมพ์ | รองรับอินเทอร์เฟซ 18 ภาษาเต็มรูปแบบ; การตัดบรรทัดอัจฉริยะ, กฎเครื่องหมายวรรคตอน CJK, เลย์เอาต์สองทิศทางภาษาอาหรับ (BiDi RTL) พร้อมการเชื่อมตัวอักษรธรรมชาติ |
| ออฟไลน์และการซิงค์ | ติดตั้งเป็น PWA บนเดสก์ท็อปและมือถือได้; ป้องกันการเขียนทับข้ามแท็บด้วย Web Locks, บันทึกฉบับร่างอัตโนมัติทุก 250ms พร้อมแจ้งเตือนก่อนปิดหน้าต่าง |

## คุณสมบัติเด่น

- **ลายมือเสมือนจริง**: การสุ่มรบกวนที่ควบคุมด้วย seed จะปรับขนาดตัวอักษร ระยะห่าง ความเอียง การเบี่ยงเบนของเส้นบรรทัด และความล้าในการเขียน ผลลัพธ์แต่ละครั้งจะไม่ซ้ำกัน และการบันทึก seed ช่วยให้สร้างผลลัพธ์เดิมซ้ำได้ 100%
- **การจัดพิมพ์อัจฉริยะและข้อความสองทิศทาง**: รองรับ 18 ภาษาอย่างสมบูรณ์; กฎขึ้นต้น/ลงท้ายบรรทัด CJK, การเยื้องหน้าย่อหน้า, การแบ่งหน้าอัตโนมัติ และการจัดชิดขวาของลายเซ็น; ป้องกันการตัดคำภาษาอังกฤษ; รองรับการเขียนหวัดภาษาอาหรับตามธรรมชาติพร้อมป้องกันเครื่องหมายวรรคตอนคู่
- **พื้นผิวกระดาษและภาพถ่าย**: ปรับแต่งระยะห่างบรรทัดและระยะขอบกระดาษได้ละเอียด; ตารางสี่เหลี่ยมจัตุรัสที่สอดคล้องกัน; ปรับขนาดภาพถ่ายที่อัปโหลดให้พอดีกับกรอบ A4 อัตโนมัติ; เงารอยพับและแสงธรรมชาติ
- **ใช้ฟอนต์ใดก็ได้**: ฟอนต์ลายมือโอเพนซอร์สในตัว 8 แบบ (4 แบบมาพร้อมแพ็กเกจใช้ออฟไลน์ได้ + 4 แบบโหลดออนไลน์จาก Google Fonts) โหลดฟอนต์ระบบ, Google Fonts หรือลากไฟล์ `.ttf` / `.otf` / `.woff` / `.woff2` เข้ามา (ใช้งานร่วมกับ Calligraphr เพื่อใช้ลายมือของตัวเองได้)
- **การแก้ไขและขีดฆ่าที่เป็นธรรมชาติ**: รูปแบบการขีดฆ่า 13 แบบ (เส้นเดี่ยว, เส้นคู่, เส้นหยัก, รอยขีดขยุกขยิก) ควบคุมด้วยความน่าจะเป็น; ขีดฆ่าคำผิดพร้อมเขียนคำแก้ไว้เหนือบรรทัด; แถบเครื่องมือบนผืนผ้าใบรองรับการวาดลูกศร ร่างภาพ และวงกลมด้วยแปรง พร้อมยางลบ ล้างลายเส้นของหน้านี้ และเส้นไกด์ระยะขอบ
- **โปรไฟล์การเขียน**: 4 โปรไฟล์พร้อมใช้ในคลิกเดียว (นักเรียนตัวอย่างมีวินัย, จดโน้ตธรรมชาติประจำวัน, ลายมือเขียนเร่งรีบ, การบ้านมาตรฐานโรงเรียน) ปรับความเข้มของการรบกวน พื้นผิวการเขียน และโอกาสในการแก้ไขได้ทันที

## ไวยากรณ์มาร์กอัป

ใช้แท็กมาร์กอัปแบบอินไลน์ในข้อความโดยตรงเพื่อกำหนดการขีดฆ่าและไฮไลต์อย่างแม่นยำ:

| ไวยากรณ์ | ผลลัพธ์ที่แสดง |
|---|---|
| `~~คำผิด~~` หรือ `[del]คำผิด[/del]` | ขีดฆ่าข้อความ |
| `[del:คำถูก]คำผิด[/del]` | ขีดฆ่าคำผิดและเขียนคำที่ถูกต้องไว้เหนือบรรทัด |
| `[u]ไฮไลต์[/u]` | ขีดเส้นใต้แบบคลื่น |
| `[circle]ไฮไลต์[/circle]` | วงกลมล้อมรอบข้อความ (ชื่อย่อ `[圈]…[/圈]`) |
| `[box]ไฮไลต์[/box]` | กรอบสี่เหลี่ยมล้อมรอบข้อความ (ชื่อย่อ `[框]…[/框]`) |
| `[right]ลายเซ็น[/right]` | จัดทั้งบรรทัดชิดขวา (ชื่อย่อ `[靠右]…[/靠右]`) เหมาะสำหรับลายเซ็นและวันที่ |

## เริ่มต้นอย่างรวดเร็ว

1. เปิด [เดโมออนไลน์](https://shouxie.newzone.top) หรือนำเข้าไฟล์ข้อความ (`.txt` / `.docx` / `.md`)
2. เลือกรูปแบบกระดาษ ฟอนต์ลายมือ และโปรไฟล์การเขียนจากแผงด้านซ้าย พร้อมปรับความเข้มของการรบกวนหรือแสงของภาพถ่ายตามต้องการ (บนมือถือใช้ปุ่มแบ่งส่วน "แก้ไข / ดูตัวอย่าง" ด้านบนเพื่อสลับสองคอลัมน์)
3. คลิก "ส่งออก" บนแถบเมนูด้านบนเพื่อดาวน์โหลดภาพความละเอียดสูง (PNG / JPG), ไฟล์ ZIP ของทุกหน้า, PDF หลายหน้า หรือพิมพ์ด้วยขนาดมิลลิเมตรจริง

## ข้อจำกัด

- การจัดพิมพ์ภาษาละตินและ CJK ใช้การประมาณความกว้างของตัวอักษรเพื่อประสิทธิภาพการประมวลผลเอกสารขนาดยาว (ภาษาอาหรับใช้การวัดของ Canvas โดยตรง); สำหรับฟอนต์ลายมือที่มีสัดส่วนพิเศษ ปลายบรรทัดอาจคลาดเคลื่อนเล็กน้อย
- ฟังก์ชันพิมพ์ของเบราว์เซอร์จะพิมพ์เฉพาะหน้าปัจจุบันเท่านั้น; หากต้องการพิมพ์เอกสารหลายหน้าทั้งหมด ให้ใช้การส่งออกเป็น PDF
- Safari เวอร์ชันต่ำกว่า 16 ไม่รองรับ `ctx.filter` ทำให้แถบปรับความสว่างและความคมชัดของภาพพื้นหลังไม่มีผล
- เลเยอร์วาดเขียนอิสระผูกอยู่กับดัชนีหน้าในหน่วยความจำ; การแก้ไขข้อความขนาดใหญ่ที่เปลี่ยนการแบ่งหน้าอาจทำให้ลายเส้นเลื่อนตำแหน่งได้
- ในฟอนต์ที่มาพร้อมโปรแกรม มี 4 แบบที่ใช้งานออฟไลน์ได้; อีก 4 แบบ (Liu Jian Mao Cao, ZCOOL XiaoWei, Caveat, Kalam) จะโหลดจาก Google Fonts ขณะใช้งาน และจะถอยกลับไปใช้ฟอนต์ระบบเมื่อไม่มีอินเทอร์เน็ตหรืออยู่ในเครือข่ายภายใน
- ไฟล์ฟอนต์ `.ttf` / `.otf` / `.woff` / `.woff2` ที่นำเข้าจากเครื่องจะเก็บไว้ในหน่วยความจำของเซสชันปัจจุบันเท่านั้น และต้องเลือกใหม่หลังรีเฟรชหน้าเว็บ

## การพัฒนาในเครื่อง

ต้องการ Node.js **22.12+ / 24+ / 26+**:

```bash
npm install
npm run dev        # เริ่มเซิร์ฟเวอร์สำหรับพัฒนาที่ http://localhost:5173/
npm test           # รันชุดการทดสอบยูนิตด้วย Vitest
npm run lint       # ตรวจสอบโค้ดด้วย oxlint
npm run build      # บิลด์สำหรับใช้งานจริง (tsc + vite)
```

ไฟล์ที่สร้างขึ้นในโฟลเดอร์ `dist/` ใช้พาธแบบสัมพันธ์ (`base: './'`) และสามารถโฮสต์บน GitHub Pages หรือเว็บเซิร์ฟเวอร์ใดก็ได้ ดูรายละเอียดเพิ่มเติมที่ [docs/development.md](../development.md)
