# 손글씨 원고 생성기 (Text2Handwriting)

> 일반 텍스트를 자연스러운 손글씨 원고로 조판합니다. 과제, 반성문, 독서 노트를 브라우저에서 서버 업로드 없이 완전 로컬로 생성하세요.

손글씨 과제 제출, 독서 노트 정리, 반성문 작성, 손편지 인쇄에 적합합니다. 폰트만 기계적으로 바꾸는 기존 생성기와 달리 난수 시드를 기반으로 글자 크기, 기울기, 기준선에 실시간 흔들림을 주고 잉크 농담과 수정 흔적까지 사실적으로 재현합니다. 계정 생성이나 클라우드 업로드 없이 브라우저 내에서 완벽한 결과물을 얻을 수 있습니다.

## 지원 규격

| 항목 | 상세 내용 |
|---|---|
| 실행 환경 | 최신 데스크톱·모바일 웹 브라우저, 100% 클라이언트 사이드 로컬 실행; 좁은 화면에서는 편집/미리보기 단일 열 작업 영역으로 자동 전환되며 상단 세그먼트 버튼으로 전환할 수 있습니다 (Chrome / Edge 103+ 로컬 폰트 탐색 지원, Safari / Firefox 내장 감지 지원) |
| 입력 포맷 | 텍스트 직접 붙여넣기, `.txt` / `.md` (엄격한 UTF-8 검증 및 GB18030 지원), `.docx` (로컬 파싱) |
| 용지 스타일 | 6종 기본 용지 (줄노트, 원고지, A4 백지, 영어 4선지, 크라프트지, 모눈종이), 스마트폰 촬영 용지 자동 맞춤 지원 |
| 펜과 질감 | 젤펜, 만년필, 연필, 볼펜 4종 물리 펜 질감; 산란광 조명, 접힌 자국, 비네팅 및 빈티지 변색 효과 |
| 내보내기 | 현재 페이지 PNG / JPG, 전체 페이지 ZIP 압축, 다중 페이지 PDF, 숨김 iframe 기반 밀리미터 실치수 인쇄 (최대 약 435 DPI) |
| 언어 및 조판 | 18개 언어 완전 지원; 금칙 조판, 영어 단어 분리 방지, 아랍어 등 RTL 양방향 텍스트 및 필기체 연결(Cursive Joining) 지원 |
| 오프라인 저장 | PWA 데스크톱/모바일 설치 지원; Web Locks 다중 탭 동시성 보호 및 250ms 디바운스 자동 저장, 이탈 방지 확인 |

## 주요 기능

- **자연스러운 손글씨 필적**: 시드 기반 의사 난수 흔들림 — 글자 크기, 자간, 기준선 흔들림, 행 전체의 완만한 곡선, 잉크 번짐과 필기 피로 효과. 시드를 보관하면 언제든 100% 동일한 출력을 재현할 수 있습니다.
- **스마트 조판과 양방향 텍스트**: 줄 시작/끝 구두점 금칙 처리, 첫 행 들여쓰기, 다중 페이지 자동 분할 및 서명 우측 정렬. 아랍어 등 양방향 텍스트(BiDi RTL)의 필기체 연결과 괄호류 보호 기본 지원.
- **용지와 촬영 질감**: 행간과 여백 자유 조절, 원고지 정사각형 격자 자동 연동; 스마트폰 촬영 사진 자동 비율 축소; 산란광, 중앙 접힘 그림자, 렌즈 비네팅으로 자연스러운 종이 질감 연출.
- **자유로운 폰트 불러오기**: 오픈소스 손글씨 폰트 8종 (4종은 패키지에 포함되어 오프라인 사용, 4종은 Google Fonts에서 온라인 로드). 시스템 설치 폰트, Google 폰트, `.ttf` / `.otf` / `.woff` / `.woff2` 파일 드래그 앤 드롭 지원 (Calligraphr 등을 통한 개인 필체 폰트 사용 가능).
- **현실적인 수정 흔적**: 13종의 취소선 스타일 (한 줄, 두 줄, 물결선, 지그재그 덧칠 등) 자연스러운 확률 적용; 틀린 글자를 긋고 위에 교정 글자 쓰기, 강조 동그라미 및 네모 박스; 캔버스 툴바에서 브러시로 화살표, 스케치, 동그라미를 직접 그릴 수 있고 지우개, 현재 페이지 손그림 지우기, 여백 안내선도 지원합니다.
- **필기 스타일 프리셋**: 단정한 모범생, 자유로운 필기, 급하게 휘갈긴 체, 표준 과제 답안 4종의 프리셋을 원클릭으로 적용해 흔들림 강도, 필기 질감, 수정 확률을 한 번에 설정합니다.

## 마크업 문법

본문에 인라인 태그를 입력하여 취소선과 강조 표시를 수동으로 지정할 수 있습니다:

| 문법 | 렌더링 효과 |
|---|---|
| `~~오타~~` 또는 `[del]오타[/del]` | 글자 취소선 긋기 |
| `[del:수정]오타[/del]` | 취소선을 긋고 행 위에 올바른 글자 쓰기 |
| `[u]강조[/u]` | 물결 밑줄 긋기 |
| `[circle]강조[/circle]` | 글자 둘레 동그라미 치기 (별칭 `[圈]…[/圈]`) |
| `[box]강조[/box]` | 글자 둘레 사각 박스 치기 (별칭 `[框]…[/框]`) |
| `[right]서명[/right]` | 줄 전체를 오른쪽 정렬 (별칭 `[靠右]…[/靠右]`) — 서명과 날짜에 적합 |

## 빠른 시작

1. [온라인 데모](https://shouxie.newzone.top)에 접속하거나 텍스트 파일(`.txt` / `.docx` / `.md`)을 불러옵니다.
2. 왼쪽 패널에서 용지, 폰트, 필기 스타일을 고르고 필요에 따라 흔들림과 사진 조명을 조절합니다 (휴대폰에서는 상단의 "편집 / 미리보기" 세그먼트 버튼으로 두 열을 전환합니다).
3. 상단 헤더의 "내보내기"를 클릭하여 고해상도 이미지(PNG / JPG), 전체 페이지 ZIP, 다중 페이지 PDF를 다운로드하거나 실제 밀리미터 크기로 인쇄합니다.

## 제한 사항

- 한글, 중국어, 영어 조판은 빠른 반응성을 위해 글자 폭 추정치를 사용합니다 (아랍어 조판만 Canvas 실측 사용). 표준 비율과 크게 다른 독특한 폰트의 경우 행 끝 위치가 미세하게 차이 날 수 있습니다.
- 브라우저 인쇄는 현재 페이지만 인쇄됩니다. 전체 문서를 인쇄하려면 PDF로 내보낸 후 인쇄하세요.
- Safari 16 미만 버전에서는 `ctx.filter` 미지원으로 용지 밝기 및 대비 조절이 동작하지 않습니다.
- 손그림 레이어는 페이지 번호에 종속되어 메모리에 저장되므로, 대규모 텍스트 편집으로 페이지 분할이 변경되면 위치가 어긋날 수 있습니다.
- 내장 폰트 중 4종은 패키지에 포함되어 오프라인에서 사용할 수 있습니다. 나머지 4종(Liu Jian Mao Cao, ZCOOL XiaoWei, Caveat, Kalam)은 실행 시 Google Fonts에서 로드되며, 오프라인이나 사내망에서는 시스템 폰트로 대체됩니다.
- 로컬에서 가져온 `.ttf` / `.otf` / `.woff` / `.woff2` 폰트 파일은 현재 세션 메모리에만 유지되며 새로고침 후 다시 불러와야 합니다.

## 로컬 개발

Node.js **22.12+ / 24+ / 26+** 버전이 필요합니다:

```bash
npm install
npm run dev        # 로컬 개발 서버 시작 http://localhost:5173/
npm test           # 단위 테스트 실행 (Vitest)
npm run lint       # 정적 코드 분석 (oxlint)
npm run build      # 배포 빌드 (tsc + vite)
```

빌드 결과물인 `dist/`는 상대 경로를 사용하므로 GitHub Pages나 인트라넷 서버에 바로 호스팅할 수 있습니다. 자세한 아키텍처와 언어 추가 방법은 [개발 문서 (docs/development.md)](../development.md)를 확인하세요.
