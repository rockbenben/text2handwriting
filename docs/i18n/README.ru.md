# Генератор рукописного текста (Text2Handwriting)

> Превращайте обычный текст в реалистичные рукописные страницы прямо в браузере без отправки данных на сервер.

Создан для оформления рукописных домашних заданий, конспектов, читательских дневников, протоколов собраний и официальных писем. В отличие от простых инструментов, которые лишь механически меняют шрифт, Text2Handwriting использует псевдослучайные возмущения под управлением сида для изменения размера букв, угла наклона, дрожания базовой линии и плотности чернил. Инструмент работает на 100% локально в браузере — без регистрации и без отправки данных на сервер.

## Возможности

- **Реалистичный рукописный почерк**: Псевдослучайные возмущения на основе сида регулируют размер символов, интервал, наклон, смещение базовой линии, ширину штриха и эффект усталости руки. Каждая генерация уникальна, а сохраненный сид гарантирует 100% воспроизводимость.
- **Интеллектуальная верстка и двунаправленный текст**: Полная поддержка 18 языков; строгие правила переноса и пунктуации CJK, красная строка, авторазбивка на страницы и выравнивание подписи по правому краю; защита целых слов в латинице; нативная арабская вязь с защитой парных знаков препинания.
- **Текстуры бумаги и фото**: Точная настройка межстрочного интервала и полей; квадратные ячейки сетки; автоматическое масштабирование загруженных фото под пропорции A4; реалистичные градиенты освещения, складки и виньетки.
- **Любые шрифты**: 8 свободных рукописных шрифтов (4 в комплекте для офлайн-использования + 4 загружаются из Google Fonts онлайн). Загружайте системные шрифты, Google Fonts или собственные файлы `.ttf` / `.otf` / `.woff` / `.woff2` (поддерживается Calligraphr для создания шрифта из своего почерка).
- **Естественные исправления**: 13 стилей зачеркивания (одинарная линия, двойная, волнистая, штриховка) с настраиваемой вероятностью; зачеркивание опечаток с написанием исправления сверху; панель инструментов холста позволяет рисовать от руки стрелки, эскизы и обводки, а также переключать ластик, очистку рисунков текущей страницы и направляющие полей.
- **Профили письма**: 4 готовых профиля (Прилежный отличник, Живые заметки, Спешная запись, Типовая домашняя работа) одним кликом применяют интенсивность возмущений, характер письма и вероятность исправлений.

## Синтаксис разметки

Используйте встроенные теги разметки прямо в тексте для точного управления зачеркиваниями и выделениями:

| Синтаксис | Визуальный эффект |
|---|---|
| `~~ошибка~~` или `[del]ошибка[/del]` | Зачеркнуть текст |
| `[del:исправление]ошибка[/del]` | Зачеркнуть ошибку и написать исправление сверху |
| `[u]выделение[/u]` | Волнистое подчеркивание |
| `[circle]выделение[/circle]` | Обвести текст в кружок (псевдоним `[圈]…[/圈]`) |
| `[box]выделение[/box]` | Заключить текст в рамку (псевдоним `[框]…[/框]`) |
| `[right]подпись[/right]` | Выровнять всю строку по правому краю (псевдоним `[靠右]…[/靠右]`) для подписей и дат |

## Быстрый старт

1. Откройте [онлайн-демо](https://shouxie.newzone.top) или импортируйте текстовый файл (`.txt` / `.docx` / `.md`).
2. Выберите стиль бумаги, шрифт и профиль письма на панели слева, при необходимости настройте освещение (на телефоне переключайтесь между колонками кнопками «Редактирование / Предпросмотр» сверху).
3. Нажмите «Экспорт» в верхнем меню, чтобы скачать изображения высокого разрешения (PNG / JPG), ZIP со всеми страницами, многостраничный PDF или отправить документ на печать в реальном миллиметровом размере.

## Ограничения

- Верстка CJK и латиницы использует расчетную оценку ширины символов для обеспечения мгновенной разбивки документов на сотни страниц (арабский текст измеряется через нативный Canvas); для нестандартных каллиграфических шрифтов границы строк могут незначительно отклоняться.
- Печать через браузер выводит только текущую страницу; для печати всего документа используйте экспорт в PDF.
- В Safari версий ниже 16 отсутствует поддержка `ctx.filter`, поэтому регуляторы яркости и контрастности подложки там не действуют.
- Слой ручного рисования привязан к номерам страниц в памяти; масштабные правки текста, меняющие разбивку страниц, могут сдвинуть нарисованные элементы.
- Из встроенных шрифтов 4 поставляются в пакете для офлайн-использования; остальные 4 (Liu Jian Mao Cao, ZCOOL XiaoWei, Caveat, Kalam) загружаются из Google Fonts во время работы, а без интернета или в корпоративной сети заменяются системными шрифтами.
- Локально импортированные файлы шрифтов `.ttf` / `.otf` / `.woff` / `.woff2` хранятся только в памяти текущей сессии браузера и требуют повторного выбора после перезагрузки страницы.

## Локальная разработка

Требуется Node.js **22.12+ / 24+ / 26+**:

```bash
npm install
npm run dev        # запуск локального сервера разработки на http://localhost:5173/
npm test           # запуск набора модульных тестов Vitest
npm run lint       # статический анализ кода (oxlint)
npm run build      # сборка для продакшена (tsc + vite)
```

Результаты сборки в папке `dist/` используют относительные пути (`base: './'`) и могут размещаться на GitHub Pages или любом веб-сервере. Подробности об архитектуре и добавлении новых языков см. в [docs/development.md](../development.md).
